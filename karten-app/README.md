# Karten ziehen

Kleine Handy-App (Web-App) zum zufälligen Ziehen von Karten.

- **Ziehen:** einmal tippen startet das Durchlaufen, nochmal tippen stoppt. Die gezeigte Karte ist gezogen und landet sofort in der Historie.
- **Name & Notiz:** optional, auch später in der Historie änderbar.
- **Historie:** wird nur auf dem jeweiligen Handy gespeichert (kein Konto, keine geteilte Datenbank).
- Funktioniert nach dem ersten Öffnen auch offline.

Gehostet kostenlos über GitHub Pages.
